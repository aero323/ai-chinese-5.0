# 中文课 — 数字人老师 + HSK 3.0 课程

这是一个**正经的中文教学产品**：一位数字人老师做入学分级面谈，判定你该学到 HSK 几级并讲清依据，
然后按 HSK 3.0 的课程体系一节一节地教。**《生活剧场》是另一个相对独立的部分**——课后的实践场，
今天的课上完了才开门。

两部分的关系只有一个交接点：**课上完 → 去剧场把学过的话用一次 → 回来，课号推进一节。**
剧场里不教新词，只用学过的。学生应当一眼就看出来：这是一门课，不是一个游戏。

| 文件 | 说明 |
|---|---|
| `index.html` | 教学端 · **桌面版**：入学分级面谈 + 课程首页 |
| `mobile.html` | 教学端 · **移动端**：装在手机框里的 App，分级面谈 + 今天 / 课程 / 老师 + 课时六步 |
| `theater.html` | 生活剧场（课后实践场，原沉浸式剧场原样保留），右上角可切经典版 |
| `classic-prototype.html` | 经典版原型，被 `theater.html` 以 iframe 打开 |
| `assets/` | 剧场素材；若放入 `teacher-portrait.jpg` 会自动用作数字人老师形象 |

直接双击 `index.html` 或 `mobile.html`（`file://` 即可）。或 `python3 -m http.server 8931`。
两端共用同一套 `cc.*` 本地状态，所以在桌面版做完分级，移动端打开就是同一个学生。

## 移动端（`mobile.html`）

视觉沿用 `classic-prototype.html`：420×900 的设备框、暖纸底、紫色主色、圆体字、大圆角，
底部浮一条三 tab 胶囊。内容则是教学端那一套。

窗口窄了会自动切成**铺满视图**（整页就是一台手机）。想在窄窗口/右侧预览里固定看设备框，
打开 `mobile.html?frame=1`，或点外层栏的「铺满」／状态栏中间的「手机框」开关（`?frame=0` 强制铺满，
选择记在 `cc.view`）。

**进 App 先是老师的全屏课堂**——数字人占满一屏，说今天这节课要干什么，底下一个「上课」，
再往上滑才是今天的课卡。三个 tab 是**今天 / 课程 / 老师**：

首课结课时，主按钮直接进入**内嵌在移动端里的竖版课后剧场**（六幕：序章 → 楼道 → 门口 → 熊猫老师示范 → 小广场 → 夜市收束；
逐拍保留转场、对白、TPRS 追问、听辨题和迁移选择题），不再跳到独立页面。剧场谢幕回到「今天」后，首页顶部会出现一张 30 秒的老师偏好卡，确认「字幕中文在上 /
母语在上」和「刚才的语速是否合适」。两项选择会记住，并作用于之后的讲解字幕与语音速度。
每完成一轮，剧场入口下方还会出现「你已认识的人 / 街区动态」：林浩、阿岚、周远、陈叔的生活状态随这一轮剧情更新，并预告下一集；它只负责关系和故事向前走，不额外增加练习。

- **今天**：全屏课堂打头，下面是今日课卡（目标、六步、八个生词横向卡条）与课后实践的门。
- **课程**：HSK 等级卡（现在 → 目标、距考试天数、整段进度）、**星星墙**（每课一颗星，
  已上完的金色呼吸、今天那颗紫色脉冲并挂着一个「+1」；下面是一周的星条，上过课的那天点亮）、
  **六枚星章**（起步 / 问候 / 十课 / 一家人 / 声调 / 说时间，点已点亮的会炸一圈小星星）、
  四项账本、六个单元的课程表（单元行带星标，点任一单元直接跳到那一课）、老师的分级依据、口径说明弹层。
  星星只做情绪价值：进 tab 会从今天那颗星炸一次，结课时从「上课」按钮再炸一次。
- **老师**：数字人画面 + 记忆标签 + 六个入口（讲解这个词 / 为什么这么说 / 让我练一次 /
  慢一点再说 / 我的进度 / 重新评估我）。

**分级面谈**改成一屏一问，八屏：老师全屏出场 → 目的 → 考期 → 听辨 → 认字 → 口语自评 →
每日时长 → 判定屏。每屏顶上有老师的一句话气泡，判定屏和桌面版同一套算法。

## 课时：讲解与练习交替

一节课不是六道练习题，**讲解是主干，练是用来检验刚讲完的东西**。第 15 课（第三单元「时间」）
被拆成 **15 段：8 段全屏讲解 + 7 段练习**，交替推进：

| 步 | 顺序 |
|---|---|
| 本课目标 | 讲：导课（为什么先学时间、学完能说什么） |
| 生词 | 讲：八个词分三组 → 练：八张生词卡 → 讲：几 和 多少 的辨析 |
| 语法点 | 讲：用「几」问数目 → 练：替换 → 讲：时间词作谓语、不用「是」→ 练：替换 |
| 听力 | 讲：听力策略（只抓数字 + 后面那个字）→ 练：三段听辨（答错可叫老师重讲） |
| 跟读与口语 | 讲：三声连读（几点 读作 jí diǎn）→ 练：三句跟读 + 一次自由表达 |
| 当堂小测 | 练：五题 → 讲：讲评两个最常错的地方 |
| 结课 | 得分、掌握度三档、用时，写进账本并开门去剧场 |

主讲解共 **39 句**，另有 3 段「答错重讲」共 6 句。

### 全屏讲解播放器

老师占满整屏，**板书作为浮层长在他身上**，讲到哪里长到哪里。字幕跟着走，中文在上、母语在下。

- **自动播放，段末插一问**：一句接一句自动往下走（时长按字数估算），讲完整段弹出一个确认问题，
  答对给确认、答错给解释，然后才放行到练习。
- **控制条**：暂停 / 重说这句 / 说慢一点（时长 ×1.5）/ 我没听懂。
  「我没听懂」会就地插入这一段的 `again` —— 老师换一套更简单的说法重讲，每段只能用一次。
- 点板书区域可以跳到下一句；桌面版右下角另有「跳过讲解」。
- 板书上有例句时，右上角出现一个喇叭，可以单独听那一句中文。

### 七种板书

`lesson-core.js` 里的 `boardHTML()` 负责渲染，两端共用结构、各自配色：

| 类型 | 用途 |
|---|---|
| `list` | 要点列举（几点？／哪天？） |
| `kv` | 本课概况（生词 8 个 · 语法 2 个 · 25 分钟） |
| `line` | 一个整句，可高亮其中几个字 |
| `group` | 生词分组，逐组长出来，可整组高亮 |
| `slot` | 结构槽位：现在 ▢ 点 → 把「几」填进去 |
| `rows` | ✗／✓ 对照，错的那行划掉，附一行说明 |
| `tone` | 声调曲线（SVG 画四声），支持变调前后对比 |

### 两端共用一份数据

课时内容与全部讲解在 **`lesson-core.js`**，桌面版和移动端都用经典 `<script src>` 加载它
（`file://` 下可用，所以不能改成 ES module）。改一句讲解词、加一段板书，两端同时生效。
要加新课，复制 `L15` / `TALKS` / `SEGS` 这三样的写法即可。

掌握度刻意给得克制：一节课不会让八个词全部变成独立，剩下的排进后面几课的复习。
试听用浏览器设备合成音（`speechSynthesis`，zh-CN）示意；按住说话是界面模拟，不含真实识别。
讲解里的「老师在说话」目前是字幕 + 波形的模拟，接入真实数字人后换成口型同步的视频流即可，
节拍时长（`beatDur`）正是为此留的接口。

## 等级骨架：新 HSK 3.0（三等九级）

课程按 **2025 年 HSK 考试大纲**排。累计口径：

| 等级 | 累计词汇 | 认读汉字 | 书写汉字 | 本课程课数 |
|---|---|---|---|---|
| HSK 1 | 300 | 246 | — | 40 |
| HSK 2 | 500 | 371 | 100 | 30 |
| HSK 3 | 1000 | 655 | 250 | 65 |
| HSK 4 | 2000 | 1096 | 400 | 120 |
| HSK 5 | 3600 | 1527 | 550 | 185 |
| HSK 6 | 5400 | 1940 | 700 | 215 |
| HSK 7–9 | 11000 | 3088 | 1200 | — |

**两个数字容易混**：2021 年《国际中文教育中文水平等级标准》把一级定为 500 词，那是**教学框架**；
2025 年**考试大纲**一级为 300 词，才是新考试的出题依据。本课程用后者，并在界面里写明口径
（账本右上角与「看各级口径」弹层）。「本课程课数」是我们自己的排课，不是大纲规定。

**考期锚点**：HSK 3.0 首场正式考试为 **2026-12-13**，在那之前的常规考次仍考 HSK 2.0。
首页与判定屏里的「还有 N 天」按打开当天实时计算。

## 入学分级面谈（五步）

数字人老师主持，不是问卷：

1. **学习目的** — 在中国工作 / 留学 / 考证 / 生活 / 家人说中文 / 兴趣。每个目的挂着一个目标等级。
2. **考试时间线** — 要不要赶 12 月 13 日那场。
3. **摸底三题** — 听辨一句（选项用学习者母语给出，不显示中文原句）、勾出认得的词（不标等级，避免提示）、口语自评。
4. **每日时长** — 15 / 25 / 45 分钟，换算成每周课数。
5. **判定屏** — 这是整个产品可信度的核心：给出**起点等级与目标等级**，并写出三条理由
   （引用你自己的回答与摸底结果）、口径声明、总课数与预计周数，以及一条具体的考试建议，例如
   「按每天 25 分钟，到 12 月 13 日你大约走到 HSK 2 的 63%，HSK 2 还没学完。两条路：这次稳妥报
   HSK 1，或者把每天时间加到 45 分钟去赶 HSK 2。」目标等级可以当场调低，起点按摸底来。

## 课程首页

左栏是数字人老师，右栏是课。老师每天说一句针对你的话（上一课哪个词稳了、哪个还要再带一次）。

**今日课**按标准课时排：本课目标 → 生词 → 语法点 → 听力 → 跟读与口语 → 当堂小测，
每一步标着时长或题量；下面列出本课八个生词。课时长度取你面谈时报的每日时长。

**等级账本**用 HSK 记账：当前等级与目标等级、到目标还有多少课、词汇 / 认读汉字 / 书写汉字 /
课程语法点四项进度，以及距考试的天数。书写汉字在 HSK 1 显示「HSK 2 起考」。

**老师的分级依据**把面谈结论摊开：目的、摸底结果、每日时长，以及第 20 课后会重新摸底的承诺。

门口的「进入剧场」直接落到经典版 App 视图的那一天流程（`classic-prototype.html?go=episode`）；

## 教学增强：字形卡与声调实验室（三语共用）

课时段位表在 `lesson-core.js` 之外又包了一层（`EXT_SEGS`）：**中、EN、ID 三个版本都多出两段**，
位置和文案按各语言原生写（`pick(zh,en,id)`），不是翻译腔：

1. **字形卡（`seg.kind === 'shapes'`，生词之后）**。把本课八个字逐个拆成部件——
   点 = 占 + 灬（下面四个点来自「火」）、明天 = 日 + 月 + 一 + 大、号 = 口 + 丂——
   每行都能点读，并明说 **HSK 1 不考手写**，先认形，写字的练习从 HSK 2 才开始。
2. **声调实验室（`seg.kind === 'tonefeet'`，t4「三声连读」讲解之后）**。三块：
   同一音节四调对照（妈/麻/马/骂，各带义项）、三组最小对立对（几/鸡、点/店、四/十，
   最后一组顺带纠 s 与 sh）、以及把变调从「几点」推广开的小结题。全部可点读。

设计意图：讲解只讲一遍是不够的，得给一个**可反复点、可自己验证**的环节。
段末小结题的判分照旧走 `LA` 的作答状态，结课统计不受影响。

## 印尼语版（顶部 ID 开关）

顶部语言组是 `中文 / EN / ID`。**ID 版对零基础的印尼语学习者单独加了一层**，中/EN 两版
的文案、段位与交互完全没动：

- **界面全印尼语**。ID 模式下界面走中文文案分支，再由一份整句词典译成印尼语
  （`ID_EXACT_RAW` 约 350 条，覆盖讲解、板书、段末检查、生词、练习、小测、老师语气）。
  生词例句、跟读句、排序词块等**目标语内容不翻译**，用 `data-no-id` 标出来跳过。
- **拼音层**。选项、积木、板书格里凡是出现汉字的地方，ID 模式一律在下面补一行拼音——
  印尼语母语者没有声调经验，认字前先得能读出来。
- **字形卡与声调实验室**：这两段已经**三语共用**了，见上一节；ID 版只是把它们讲得更针对
  印尼语母语者（无声调、无 sh、无送气对立）。
- **录音改成真的录、真的能回放**。原型原来的跟读反馈是 `Math.random()` 假判定；ID 版用
  `MediaRecorder` 录下来，回放给学习者自己听，并**明说「原型不自动评分」**，再给两条自评清单
  （时间词是否在动词前、几点是否读 jí diǎn）。麦克风不可用时如实说明，不假装录上了。
- **复习队列**。结课时把本课八个词排进 **1 / 3 / 7 天** 的复习队列（`cc.review`），
  结果页与今天页都能看到下一次到期时间，兑现结果页「排进后面几课复习」这句话。

  生词页的词性（量词、名词、代词）同理。

## 自检：`?smoke=1`

两端都内置了一个冒烟测试，打开 `index.html?smoke=1` 或 `mobile.html?smoke=1` 即可运行，
结果直接盖在页面上（✓ / ✗ 逐项列出，37 项）。它会**真的点一次「上课」**，然后把课时的
15 段、11 组讲解（逐句走到底 + 答一次段末问）、九位老师各渲染一遍，任何一处抛异常都会标红。

这个测试是补出来的：曾经有一版点「上课」没反应——`renderTalk()` 假设讲解状态已存在，
但刚进第一段时它还是 `null`，于是取 `tk.id` 直接抛错、渲染中断，而每进入一段新讲解
状态都会被清空，所以整节课从头到尾都走不通。只截图看「摆好状态的某一屏」是发现不了这类
问题的，必须真的点一次。改动过渲染逻辑之后请先跑一遍这个。

## 进度保存与断点续上

课时进度（当前段、小节、已作答）会写进 `cc.lsn`：**上到一半被打断，下次打开从那一段接着上**，
并提示「接着上，从第 N / 15 段」。主动点 × 退出或正常结课会清掉这条记录，所以不会出现
不想要的续上。

`LS` 对**存储被禁用**的情况做了兜底。无痕模式、沙箱预览、部分浏览器的 `file://` 会让
`localStorage` 读写静默失败；原先的实现一失败就返回默认值，等于整个状态悄悄清零——
而路由的第一道判断是 `if (!S.teacher) renderPick()`，于是人就被甩回**选老师**这个最靠前的屏，
表现正是「上课上到一半突然回到最开始」。现在的做法是启动时探测一次，不可用就退回内存存储，
写入永远同时写一份到内存；同时在界面上明说「这个环境不保存进度，刷新后会从头开始」，
不假装一切正常。

听力材料和讲解词写出来——这是真正的内容工程量。
课程内容目前只到 HSK 1 的六个单元，且每个单元一节样课；HSK 2 以上只有等级与课数，没有课。

## 剧院版做了什么

**全屏沉浸的戏剧效果**

- 全屏舞台：人物肖像做 Ken Burns 式推拉镜头，幕与幕之间交叉溶解、遮罩转场

- **后台排练室**（新用户默认进入，随时可跳过）：声调耳朵 + 拼读直觉 + 第一句话，
  3 分钟、全拼音、不认汉字；试听使用设备合成音（原型示意）。
  支持 **中文 / English / Bahasa Indonesia** 三语切换（默认英文），大卡片全屏呈现；

  母语译文常显，按 `H` 或右上角「字」随时打开汉字；正式版第 4 集起会自动邀请升级。
- **TPRS 追问**：第一幕把目标句「你是新搬来的吗？」展开成三组确认问句
  （是/否 → 新搬来的/老邻居 → 是你/是我），听懂点一下即可，答错不失败——

## 印尼语辅助（ID 开关）

右上角 **ID** 按钮（快捷键 `I`）为印尼语母语学习者准备了一层辅助，开关状态实时作用于整个界面：

- **印尼语讲解**：字幕、旁白、任务提示、选项、反馈、老师解释、谢幕回顾全部附带印尼语；
  短标签（按钮、状态 chip、章节名）会直接切换成印尼语。
- **汉字悬停**：开启后每个汉字 / 词组下方出现细线，鼠标悬停显示**拼音 + 印尼语释义**
  （例如「新搬来的 → xīn bān lái de · baru pindah ke sini」）；手机端点一下也能弹出。
- **老师会用印尼语解释**：左侧熊猫老师面板的第三项在 ID 打开时变成「用印尼语解释这句」，
  直接给出当前这句话的印尼语含义。
- 术语表：`CHAR_PY`（逐字拼音）+ `WORD_GLOSS`（词组拼音与印尼语释义，最长匹配）在 `index.html` 顶部，
  可继续补充词条；剧本里每句台词都有 `id:` / `idPrompt:` / `idTarget:` 等字段，便于替换成其他母语。
